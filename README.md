# media-catalog-system
Каталог фильмов и сериалов с ручным и API-пополнением, поддержкой типов контента и рецензиями. Проект для конкурса «Хайтек.Юниоры».

## Источники данных

- **TMDB** — основной: постеры, описания, жанры, режиссёры, сезоны, трейлеры.
- **Кинопоиск** ([kinopoisk.dev](https://kinopoisk.dev)) — дополняет TMDB: рейтинги Кинопоиска и IMDb, ссылка на страницу фильма, «где смотреть» (Иви, Okko, Кинопоиск и др.). Если у фильма нет постера или описания в TMDB, берутся из Кинопоиска. Фильм можно найти и добавить через Кинопоиск (вкладка в окне поиска, либо вставить ссылку вида `kinopoisk.ru/film/301/`).
- В разделе «Полная версия» на странице фильма можно отметить свои подписки (Иви, Кинопоиск и т. д.): сайт покажет, где фильм доступен именно вам.

### Настройка ключа Кинопоиска

Запросы к Кинопоиску идут через сервер, ключ в браузер не попадает.

1. Скопируйте `server/.env.example` в `server/.env` и впишите ключ: `KINOPOISK_API_KEY=ваш_ключ`. Файл `.env` в git не попадает.
2. Запустите `node server.js` в папке `server`. В консоли появится «Кинопоиск: ключ найден».
3. Проверить связь можно на странице `check.html` (шаг 5).

Без ключа сайт работает как раньше, только с TMDB.
